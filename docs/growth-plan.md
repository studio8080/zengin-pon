# 集客と認知の計画（全銀ポン／ここ企画の制作実績として）

作成: 2026-09-18。広告費をかけない前提。上から順に、効きめが大きく手間が小さい。
**やらないこと**: 相互リンクの大量依頼、自作自演の口コミ、AI向けの隠し文、中身の薄いページの量産、誇大な表現。

## 0. 数字の見かた

- いまはアクセス解析を入れていない。当面は Search Console（表示回数・クリック・検索語）と Stripe（申込み）だけで足りる
- GA4 を入れるなら、`config.js` の `GA_MEASUREMENT_ID` に入れる前に `privacy.html#external` と `security.html` を直す。
  **測定IDは1文字ずつ照合する**（ほかのサイトで、1文字の入力違いで2週間データが取れなかったことがある）。
  入れたあと、リアルタイム画面で自分のアクセスが見えることを確かめる。振込データや入力値をイベントに載せない
- 月に1回、`docs/seo-ai-audit.md` の「AIに聞いてみた」を同じ問いでくり返す

## 2. 今月やること

### 2-1. 載せてもらえる場所に登録する（無料）

審査や掲載の条件はそれぞれ違う。**いまの事実だけを書く**（利用者数や実績の数字は、出せるようになってから）。

| 種類 | 候補 | 書く内容 |
|---|---|---|
| フリーソフト・Webサービスの紹介 | 窓の杜（情報提供フォーム）、Vector（Webサービスの登録）、フリーソフト100 | 「登録不要・ブラウザだけ・データを送信しない」 |
| SaaS 比較・レビュー | ITreview、BOXIL、ミツモア など | 掲載条件（法人限定・有料枠）を先に確かめる |
| 開発者むけ | Qiita / Zenn に技術記事、GitHub の README | 下の 2-2 |
| 地域・業界 | 京都の商工会議所・よろず支援拠点の事例募集、取引のある士業の先生 | 顔の見える紹介がいちばん強い |
| プレスリリース | PR TIMES（スタートアップむけの無料枠の条件を確認）、無料の配信サービス | 下書きは 4。ほかの掲載先の文面は `docs/outreach-kit.md` |

### 2-2. 記事を書く（ここ企画の名前で）

全銀フォーマットで検索する人の半分は「自分で作ろうとしている人」。その人たちに役立つ記事が、いちばん自然なリンクの元になる。

1. **「全銀フォーマットを JavaScript で作る。120バイト固定長と JIS X 0201 のはまりどころ」**（Zenn か Qiita）— 下書き `docs/articles/zenn-zengin-format-js.md`
   半角カナの濁点が2文字になる話、法人略語、ゆうちょの記号番号、改行コードで銀行に弾かれる話。末尾にツールと解説ページへのリンク
2. **「振込データをサーバーに送らない設計にした理由」**（会社サイトのお知らせ、または note）
   ブラウザ内処理、CSP、SRI、署名つきライセンスキー。制作実績としての読みものになる
3. **「Excel の振込一覧がそのまま読めない7つの理由」**（サイト内の記事に育てる）
   結合セル、合計行、見出しの揺れ、全角数字、銀行名だけでコードが無い、ゆうちょ、名義が漢字

記事には実測できる事実だけを書く。ツールの宣伝は最後の1段落だけにする。

### 2-3. 士業・事務代行の人に届ける

- 社労士・税理士は「顧問先の給与振込データを作る」場面がある。Pro の「振込元プロファイル複数」はそのための機能
- 知っている先生に1人ずつ、用途を添えて案内する（一斉メールはしない）。使ってもらえたら、感想を載せてよいか**本人に確認してから**掲載する
- `security.html` と `legal.html` は、事務所の中で説明するときの資料として渡せる

## 4. プレスリリースの下書き

> **ここ企画、Excel の振込一覧を全銀フォーマットに変換する Web ツール「全銀ポン」を公開**
> ―― 登録不要・1回20件まで無料。振込データはブラウザの外に出さない設計
>
> ここ企画（京都市）は、給与振込・総合振込の一覧表（Excel／CSV／PDF）を、ネットバンキングに取り込める
> 全銀協フォーマットのファイルに変換する Web ツール「全銀ポン」（https://zenginpon.kokokikaku.com/）を公開しました。
>
> **背景**: 少人数の会社や個人事業では、振込先を1件ずつネットバンキングに手入力していることが少なくありません。
> 一括で取り込める「全銀フォーマット」は固定長・半角カナという独特の形式で、Excel から作るのは手間がかかります。
>
> **特長**
> 1. 列の並びや見出しがバラバラな表でも、自動で整理して読み込みます
> 2. 銀行名・支店名からコードを補い、口座名義を半角カナと法人略語に直します。ゆうちょ銀行の記号番号にも対応します
> 3. 変換はすべて利用者のブラウザの中で行い、振込先の一覧をサーバーに送信しません。AIによる推測も使いません
>
> **料金**: 1回20件まで無料（登録不要）。件数無制限の Pro は月払い480円／年払い4,800円（税込）。
> あわせて、銀行コード検索、ゆうちょ記号番号の変換、口座名義のカナ変換の無料ツールを公開しています。
>
> 本サービスは振込データ（ファイル）の作成のみを行い、送金は行いません。
>
> ここ企画について: 小さな店や会社の仕事を少し軽くする道具を作っています。https://kokokikaku.com/
> お問い合わせ: studio@kokokikaku.com

出す前に、実銀行での取込テストを済ませておく（「取り込めました」と言える状態にしてから）。
