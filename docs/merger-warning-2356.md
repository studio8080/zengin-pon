# 興栄信用組合（2356）の合併注意

2026-11-08 UTC更新。振込先の2356に注意を付ける最小の実装について、根拠・仕様・限界を記録する。
検証結果、対象SHA、CIおよび公開確認の記録は対応PRに残す。

## 根拠と対象

- [新潟縣信用組合の公式資料](https://www.niigata-kenshin.co.jp/uploads/20261001_gappeikinen.pdf) 1ページ：令和8年11月24日の新潟縣信用組合・興栄信用組合の合併案内。2026-11-08に再確認。
- [三菱UFJファクターの金融機関異動一覧](https://www.muf.bk.mufg.jp/collect/wide/bank/)：2026年11月24日の両組合の合併に伴い、旧興栄の金融機関番号・店舗番号・一部店舗名が変更され、口座番号は変更されない旨の案内。2026-11-08に再確認。ワイドネットの口座振替向け資料であり、振込受付や全サービス共通の条件を保証する根拠ではない。
- [金融庁の2026年9月29日公表](https://www.fsa.go.jp/news/r8/ginkou/20260929.html)：組織再編成等実施計画の認定。最終の合併認可を確認した資料ではない。

新店番の完全な対応表と最終行政認可は未確認。別担当で403となった店舗表PDFは取得・再試行していない。
新銀行・店番の対応を推測しない。同梱辞書には2356と5支店が残るため、merged.jsonへの追記だけでは注意が出ない。

## 挙動と限界

src/dict.js の銀行補完後、支店照合前に2356の行へ既存の _warn として次を1件追加する。同じ注意が既にある場合は重複させない。

> 興栄信用組合（2356）と新潟縣信用組合の2026年11月24日付の合併について公式案内があります。振込指定日を確認し、事前に作成する場合も受取人と金融機関の公式案内で最新の口座情報（金融機関・店番など）を確認してください。コードは自動変更しません。

明示コード、名前欄のコード、正式名・辞書名・カナ補完に適用。支店不明・空欄でも注意する。
金融機関・店番・口座番号・名義・金額を合併先へ変換せず、既存の銀行名不一致や支店不明の注意を残す。
一般的な移行基盤は追加せず、辞書・履歴・merged.jsonと既存0120→0121の扱いは変更しない。

画面の指定日は年月日、全銀出力はMMDD。src/app.js の rebuildRows は resolveRows(rows) を呼び、振込日を渡さない。
将来振込の事前作成も対象にするため、作成日や指定日で注意を消さない。日付後も「合併済み」や「合併予定」と自動で断定しない。
公式案内の変更や辞書の更新時には、この注意の必要性と文言を再点検する。

既存画面では該当行が「確認」、集計で「要確認」になり、本文をメッセージ欄に表示する。
警告だけではダウンロードを止めず、renderPreview のOK件数にも警告行が含まれる。銀行が受け付けることは保証しない。
辞書全体の読込失敗時はアプリが辞書照合を省略する既存仕様のため、本注意も表示されない。
対象は再照合される振込先の行。振込元や過去に生成・保存したファイル、履歴からの再ダウンロードを再検査する機能ではない。
振込データの外部送信、外部案内の自動読込、AI/OCR、本番ライセンス・秘密鍵の利用は追加していない。
