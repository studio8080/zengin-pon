# 検索・AI検索まわりの点検記録

点検日: 2026-09-18 ／ 対象: https://zenginpon.kokokikaku.com/ ／ 次回の点検: **2026-10-19 ごろ**

> この記録は「サイトが正しく読まれ、正確に引用される状態か」を点検したもの。
> AIのおすすめや検索順位を操作する手段は無いし、やらない。点数もつけない（出せる根拠が無い）。
> 検索もAIも反映は遅い。変更の効果が見えるのは早くて30日後。

## 1. 先に結論（効く順の5件）

| # | 見つけたこと | 影響 | 対応 |
|---|---|---|---|
| 1 | メニューとフッターを JavaScript で差し込んでいた。JS を実行しないクローラーには、内部リンクも運営者表記も見えていなかった | 大 | **済** HTML に静的に埋め込む方式へ（`tools/build-site.js`） |
| 2 | 「全銀フォーマットとは」に答えるページが無かった。検索の入口が変換ツールのトップだけだった | 大 | **済** `zengin-format.html` を新設 |
| 3 | canonical と OGP が一部のページにしか無かった。運営者（Organization）の構造化データが無かった | 中 | **済** 全ページに共通で埋め込み。トップを `@graph`（Organization＋WebSite＋WebApplication）に |
| 4 | `llms.txt` が無い。`robots.txt` が AI クローラーに触れていない（ブロックはしていなかった） | 中 | **済** どちらも追加。検索・引用系と学習用を分けて明記 |
| 5 | サイトの外に存在しない。会社サイトにも、ディレクトリにも、記事にも載っていない | 大 | **未** `docs/growth-plan.md` の順で進める。ここがいちばん時間がかかる |

## 2. 点検した項目

| 項目 | 結果 |
|---|---|
| クローラーの許可 | `robots.txt` は全許可（`/data/` `/samples/` のみ除外）。GPTBot、OAI-SearchBot、ClaudeBot、Claude-SearchBot、PerplexityBot などを名指しで許可 |
| JS なしで読めるか | 本文・メニュー・フッター・パンくずは HTML にある。変換ツールの動作だけが JS |
| タイトル・説明文 | 全ページに固有のものがある。h1 は各ページ1つ |
| 内部リンク | 壊れたリンク 0（ローカルの点検スクリプトで確認） |
| 構造化データ | 構文エラー 0。WebApplication（料金3種）、TechArticle、BreadcrumbList、AboutPage、FAQPage |
| sitemap | 1,159 URL。変更していないページの更新日を今日にしない作りに直した |
| 表示速度・スマホ | 画像はほぼ使っていない。375px 幅で横スクロール 0（全15ページ） |
| 事実の一貫性 | 料金（無料は1回20件、Pro は月480円・年4,800円）が `pricing` `faq` `llms.txt` `tokushoho` 構造化データで一致 |

注: FAQPage の構造化データは残してあるが、Google は2026年5月に FAQ のリッチリザルトを廃止した。
検索結果の見た目は変わらない。ほかの検索エンジンやAIが事実を読む助けにはなるので、消していない。

## 3. 「AIに聞いてみた」の記録（スナップショット）

**やり方**: お客さんが聞きそうな言い方で検索・質問し、出てきたものをそのまま書く。
結果は回ごとに変わる。順位ではない。月に1回くり返して、向きを見る。

### 2026-09-18

- 問い: 「全銀フォーマット 変換 Excel 無料 ツール」（Web検索）
- 出てきたもの: 信用金庫・労働金庫が配っている変換ツール、Vector のフリーソフト、Qiita の解説記事、deskworklabo の VBA 記事
- 全銀ポン: **出てこない**（公開から約1週間。Search Console に登録して間もない）
- 読み取れること: 上位は「銀行が配るツール」と「作り方の解説」。後者の枠は `zengin-format.html` で狙える。
  前者には勝てないので、「並びがバラバラな表でも読める」「ゆうちょの変換」「名義のカナ」など、困りごと単位の長尾を取りにいく

次回も同じ問いに加えて、次を試す。
「ゆうちょ 記号番号 振込用 変換」「口座名義 株式会社 カナ 略語」「給与振込 全銀データ 作り方 Excel」「総合振込 CSV 全銀 変換 ブラウザ」
